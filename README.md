В чём отличие FreeBSD от OpenWRT?  

1.	На чём основан pfSense?  
FreeBSD.  

----------------------------------------------------------------------------------------------------------

2.	В чём суть pfSense?  
Программный маршрутизатор, firewall, VPN, DNS, DHCP, балансировщик нагрузки.  
Плюс, не нужно знать тонкости командной строки и проприетарные команды FreeBSD,   
чтобы описать сложный сетевой узел.  

3.	Чем отличаются OpenWRT и FreeBSD?  

----------------------------------------------------------------------------------------------------------

FreeBSD – полноценная ОС.  
Сервера, клиентские машины, виртуальные машины, всякое такое…  
У самого FreeBSD веб-морды нет, но есть pfSense, он полностью графический.  
По дефолту, у pfSense файловая система UFS (Unix File System).  
Оптимальна для небольших систем или оборудования с ограниченными ресурсами.  
Но можно поставить и ZFS. Обеспечивает высокую целостность данных и снапшоты.  
Пакетный менеджер - pkg  

OpenWRT – специализированный дистр для роутеров, точек доступа и устройств типа Raspberry Pi.  
Главным образом, предназначен для систем с ограниченными ресурсами.  
То есть, максимум функционала из минимума железа.  
У OpenWRT есть веб-морда по умолчанию, называется LuCI. Она устанавливается «из коробки».  
OpenWRT использует гибридную файловую систему, называется squashFS (только чтение).  
Пользовательские данные и настройки хранятся в перезаписываемом разделе JFFS2 (для флеш-памяти)  
с использованием оверлея, что обеспечивает защиту системы и легкий сброс настроек.  
OpenWRT решает те же задачи, что и pfSense, но для другого класса устройств (маленьких и слабых).  
Пакетный менеджер – opkg  

----------------------------------------------------------------------------------------------------------

4.	Системные требования.  

* FreeBSD 13.xx / pfSense.  

CPU: amd64, i386, ARM, PowerPC, RISC-V  
2 ядра до 50 устройств и нормальной работы NAT + firewall  
4 ядра, если много подключений + VPN (openVPN) + Suricata/Snort + гигабитный постоянно загруженный канал.  
Чем больше плюшек, тем больше ядер.  

RAM: 4 гб для универсального использования.  

HDD: 1.5 гб для установки / 8 гб для универсального использования.  

----------------------------------------------------------------------------------------------------------

* OpenWRT (любой распоследней версии).  

CPU: x86, ARM, MIPS, PowerPC и всё (ну или почти всё) из породы SoC.  
Любой проц с 1+ ядром.  

RAM: 64 мб для установки / 128 мб для нормальной работы.  

HDD: 120 мб для установки / 2 ГБ для нормальной работы.  

Вывод:  
Если собирать на Raspberry Pi 4, то только OpenWRT. Почему?  
Потому что у него только 1 нормальный Ethernet-порт, второй висит на USB-шине, что медленно.  
Для нормального роутера нужно минимум 2 порта.  
OpenWRT на RPi обычно используют как, например, VPN-клиент или AdGuard Home.  
Для этих задач подходит идеально.
